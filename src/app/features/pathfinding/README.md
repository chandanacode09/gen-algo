# Pathfinding Module (Phase 2 - Future Implementation)

This module will contain pathfinding algorithm visualizations.

## Planned Features

- Grid-based visualization (20x20 default)
- Click to place walls, start, and end points
- Algorithms to implement:
  - Breadth-First Search (BFS)
  - Depth-First Search (DFS)
  - Dijkstra's Algorithm
  - A* Algorithm
- Animate visited nodes expanding outward
- Show final path after completion

## Architecture

Similar to the sorting module, this will include:
- Algorithm service files for each pathfinding algorithm
- Grid visualizer component
- Shared control panel integration
- Statistics tracking for nodes visited, path length, etc.
