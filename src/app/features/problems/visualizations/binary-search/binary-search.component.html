How It Works

🔍

Divide and Conquer

Binary Search repeatedly divides the search space in half by comparing the target with the middle element. If they match, we're done! Otherwise, we eliminate half the array and continue searching.

⚡

Time Complexity: O(log n)

Each iteration eliminates half of the remaining elements. With each step, we halve the search space, making it extremely efficient even for large arrays. For 1 million elements, we need at most 20 comparisons!

💾

Space Complexity: O(1)

We only use three pointers (left, mid, right) regardless of array size, making this solution very memory efficient.

💡

Key Requirement

The array must be sorted! Binary Search relies on the fact that elements are in order. If the array isn't sorted, the algorithm won't work correctly.
