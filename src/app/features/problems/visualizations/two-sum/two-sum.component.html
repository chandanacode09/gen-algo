How It Works

🎯

The Two Pointers Approach

We use two pointers starting from opposite ends of the sorted array. By comparing the sum at these positions with our target, we can intelligently move the pointers to find the solution.

⚡

Time Complexity: O(n)

We only traverse the array once with our two pointers moving toward each other. Each element is visited at most once.

💾

Space Complexity: O(1)

We only use two pointers (constant extra space), making this solution very memory efficient.

💡

Key Insight

If the sum is too small, we need a larger number (move left pointer right). If the sum is too large, we need a smaller number (move right pointer left). This only works because the array is sorted!
